# Vibe List

Windows용 가벼운 할 일 체크리스트입니다.

## 기능

- 할 일 추가, 완료, 수정, 삭제 및 자동 저장
- 다크/화이트 배경
- `Ctrl + 마우스 휠` 화면 크기 조절(75%~140%)
- 항상 위에 표시
- GitHub Releases 기반 업데이트 확인 및 설치

## 설치

최신 GitHub Release에서 `VibeList.exe`를 내려받아 실행합니다. 별도 설치 프로그램은 필요하지 않습니다.

## 데이터

사용자 체크리스트와 설정은 `%LOCALAPPDATA%\VibeList`에 저장됩니다. 실행 파일을 업데이트해도 체크리스트는 유지됩니다.
