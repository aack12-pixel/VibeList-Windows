# Vibe List

Windows용 가벼운 할 일 체크리스트입니다.

## 기능

- 할 일 추가, 완료, 수정, 삭제 및 자동 저장
- `지금 할 일`과 `나중에 할 일` 두 구역
- 드래그 손잡이로 구역 안 순서 변경 및 구역 간 이동
- 다크/화이트 배경
- `Ctrl + 마우스 휠` 화면 크기 조절(75%~140%)
- 항상 위에 표시
- GitHub Releases 기반 업데이트 확인 및 설치
- 입력창과 Todo 목록에 한글·영문을 모두 지원하는 나눔고딕 정적 글꼴 적용

## 설치

`VibeList-설치파일.zip`을 내려받아 압축을 풀고 `VibeList 설치.vbs`를 실행합니다. 설치 스크립트가 `%LOCALAPPDATA%\VibeList\App`에 앱을 복사하고 바탕화면에 `VibeList` 바로가기를 만듭니다.

이 배포본에는 Smart App Control이 차단하는 미서명 EXE와 콘솔을 표시하는 CMD가 포함되지 않습니다. 생성된 바로가기는 Windows 기본 `wscript.exe`와 PowerShell을 이용해 콘솔 창 없이 실행됩니다.

배포 파일에는 나눔고딕 Regular 글꼴과 SIL Open Font License 1.1 문서가 포함됩니다.

## 데이터

사용자 체크리스트와 설정은 `%LOCALAPPDATA%\VibeList`에 저장됩니다. 실행 파일을 업데이트해도 체크리스트는 유지됩니다.
